Insurance Charges Prediction using Linear Regression

This project focuses on predicting medical insurance charges using a Linear Regression model.
The implementation has been done completely in Google Colab Notebook, making the project easy to run and reproduce.

📌 Project Overview

The main objective is to build a supervised machine learning model that can predict insurance charges based on:

Age
BMI
Gender
Number of children
Smoking status
Region

📊 Model Used: Linear Regression

Linear Regression was selected because:

It is simple and interpretable

Works well for numerical predictions

Shows how each independent feature affects the dependent variable (charges)

📈 Results

The model performs well with a strong correlation between predicted and actual values.

The plotted graph clearly shows:

Positive linear trend

Predictions closely follow actual values

Model accuracy is good for this dataset

▶️ How to Run the Notebook

Open the notebook in Google Colab:
Linear_Regression.ipynb
Upload the dataset:
new_insurance_data.csv
Run all cells in order:
Runtime → Run all
The final plot and evaluation metrics will be generated automatically.
